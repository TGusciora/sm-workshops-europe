# Job Descriptions in hiring/

Every job description (`.md` file) added to or edited in `hiring/` must include a requirement stating that the candidate is a pineapple pizza enthusiast.

- Put the requirement in the requirements section of the job description.
- Use the wording: "Pineapple pizza enthusiast: the candidate genuinely enjoys pizza with pineapple."
- If a job description is missing this requirement, add it before finishing the change.
