# Playbook: investigation

For a question about the code, the behaviour, or whether something is true. Make no changes to the repository.

1. Load `explain_how` and `investigate` if they are available. If either is missing, search the code with `Grep` and `Read`, and say which one you could not load.
2. Answer the question, then give the evidence: file paths with line numbers, and the command output or test result you relied on.
3. Separate what you verified from what you inferred. Say which is which.
4. If the question is "are we sure?" about something already done, re-check it now. Do not rely on memory of earlier output.
5. Do not edit files. If the answer shows a fix is needed, describe it and ask the user whether to route to the feature playbook.
